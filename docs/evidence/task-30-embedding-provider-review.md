# Task 30 Embedding Provider 接入审批材料

**状态：待负责人批准（PENDING_OWNER_APPROVAL）。本材料仅为审批摘要，不构成审查通过。**
**审批对象：知识库向量化（Embedding）Provider 的选定与接入。**

背景：DeepSeek 官方不提供 Embedding 模型（官方模型列表与价格页均无），Task 30 知识库真实闭环必须选定一个外部 Embedding Provider。材料基于官方文档与公开价格页整理（2026-10-25 查证）。

---

## 一、候选对比

| 项 | 方案 A：硅基流动 SiliconFlow（推荐） | 方案 B：阿里云百炼 DashScope |
|---|---|---|
| 模型 | `BAAI/bge-m3`（开源多语言，100+ 语言） | `text-embedding-v4`（通义 Qwen3 基座） |
| 价格 | **免费**（价格页标为免费，无计费风险） | ¥0.5/百万 tokens（约 $0.07） |
| API 兼容 | **OpenAI 兼容** `/v1/embeddings`，与现有 LiteLLM/Gateway 架构零改动适配 | DashScope 兼容模式亦为 OpenAI 风格，但需独立接入点 |
| 维度 / 输入上限 | 1024 维 / 8192 tokens | 64-2048 可调 / 长文本 |
| 中国大陆直连 | ✅（`api.siliconflow.cn`） | ✅（北京/香港地域） |
| 数据政策 | 平台协议未逐条审查（待验证项） | **官方明确：按量付费 API 不将用户数据用于模型训练**（帮助中心原文） |
| 质量定位 | 中英文检索效果良好（社区实测排序正确） | MTEB 多语言/中英/Code 检索较 V3 提升 15-40% |
| 费用风险 | **零**（免费模型无计费） | 低（知识库场景月费用通常 < ¥1） |

## 二、建议方案（供负责人决定）

**方案 A（bge-m3，免费）作为接入首选**，理由：零计费风险（与当前 Actions 额度受限的现状匹配）、OpenAI 兼容接口使 Gateway/凭据/预算链路改动最小、中英文效果满足知识库检索。**方案 B 作为后续升级候选**（若检索质量不足或量级增长）。

## 三、数据发送范围（接入后生效）

- Embedding 调用发送：**知识库文档的文本切片（chunk）与查询文本**——这是与 DeepSeek canary（仅固定字符串）的本质区别，**真实用户文档内容将发送给所选 Provider**。
- 单条输入上限 8192 tokens（A）或按 V4 限制（B）；每次调用即一次 HTTP 请求，无自动重试。
- 需要负责人知情并批准（对应 Task 28 审批第 2 项的同类问题）。

## 四、凭据与安全控制（复用既有链路，已验证）

- 凭据存储：Windows 凭据管理器（`secret://os/providers/<id>/credential`），与 DeepSeek 同一机制。
- 调用链路：Gateway → Policy → 预算（预留/结算）→ SecretResolver → LiteLLM，`num_retries=0`、无 fallback。
- 测试门禁：真实 Embedding 测试与 canary 同样受一次性显式授权门禁约束；**授权测试预计恰好 2 次调用**（1 次文档向量化 + 1 次查询向量化），由负责人单独授权。
- 诊断日志仅元数据（Trace ID、安全错误码），不含文本与凭据。

## 五、需要负责人决定的事项

1. 是否批准 **方案 A（SiliconFlow bge-m3，免费）** 作为 Embedding Provider 接入。（或指定方案 B/其他）
2. 是否批准**知识库文档文本切片与查询文本**发送给该 Provider。
3. 是否授权真实测试中的 **2 次调用**（在账单解锁、PG17/18 就绪后的同一验证会话中执行）。
4. 确认数据保留策略沿用现状：本地仅元数据日志，不持久化向量正文到诊断日志。

## 六、已验证 / 未验证

- **已验证**：DeepSeek 无 Embedding 模型（官方列表）；A/B 两方案的存在性、价格、API 形态（官方页）；既有安全链路（Task 28/29 测试）。
- **未验证**：A 方案平台对数据训练/保留的具体条款（其用户协议需负责人或后续法务过目）；真实调用的向量质量；B 方案 DashScope 在本机的实际兼容性。

**批准方式**：对第五节四项逐项明确批准或提出条件；确认后由记录者标注批准人与日期。
